Import and export

Starter CSV: load your things from a spreadsheet

Build a list in any spreadsheet with one row per thing, save it as CSV, and import it here. QuaTrel shows a preview before anything is saved.

ColumnRequired?What goes in it
nameyesThe label for this particular thing, e.g. "shack router"
whatyesWHAT (thing): router, hotspot, PC…
whynoWHY (role). Several roles go in one cell separated by semicolons: AllStar; DVSwitch
wherenoWHERE (location): shack, garage, cabin…
statusnoBlank means In service. Also: Spare, Surplus, Broken, Retired
whennoDate of the starting event: 20261021, 2026-10-21, or 10/21/2026. Blank means today. YYYYMMDD is the safest in Excel, which never reformats it
wiki_urlnoLink to the thing's wiki page
notesnoAnything else

Any WHAT, WHY, WHERE, or status value QuaTrel hasn't seen is added to its lists automatically.

  • quatrel-events.csv: every event, oldest first.
